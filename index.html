Open source and free

GPLv3. Runs on your own server, and your data stays there.

Install it yourself

$ git clone \
    https://github.com/Old-Steel-Arsenal/opengunstore
$ cd opengunstore
$ docker build --platform linux/amd64 \
    -f deploy/prod/Dockerfile -t opengunstore:0.1.3 .

Features

In daily use at an independent FFL dealer. Built on Frappe and ERPNext v16.

Point of Sale Storage Locations Cash Drawer Form 4473 Records
CounterSerial picking, license scanning, order queues
Form 4473Sale is blocked until the 4473 is complete and NICS says Proceed
Bound bookSynced to FastBound
PaymentsPayroc terminals, split payments, daily reconciliation
Web and auctionWooCommerce and GunBroker from one inventory
DistributorsRSR and Sports South ordering and drop-ship
Cash drawerDaily count with variance check
Back roomConsignment, trade-ins, stock counts, storage map
